## Fundamentals of Data Science

This repository contains introductory-level work related to data science,
focusing on data handling, basic analysis, and an overview of common
machine learning techniques.

### Topics Covered
- Data loading and cleaning
- Exploratory Data Analysis (EDA)
- Data manipulation using Pandas
- Data visualization using Matplotlib
- Feature encoding techniques (label encoding, one-hot encoding)

### Introductory Machine Learning Concepts
- Linear Regression (basic implementation and understanding)
- Logistic Regression (classification overview)
- K-Nearest Neighbors (KNN)
- K-Means Clustering

The implementations and examples are aimed at understanding the core
ideas behind these techniques rather than advanced optimization or
production-level modeling.
